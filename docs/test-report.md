## V1 阶段：本地账号系统与游客行程绑定

### 改动范围

- 后端新增本地账号模型和认证接口：
  - `POST /api/auth/register`
  - `POST /api/auth/login`
  - `GET /api/auth/me`
  - `POST /api/auth/claim-guest`
- 密码使用 PBKDF2 哈希保存，不保存明文密码。
- 登录 token 使用 `CITY_ROUTE_AUTH_SECRET` 做 HMAC 签名。
- 原有行程接口支持 `Authorization: Bearer ...`，登录态优先于 `X-Client-Id`。
- 注册或登录时，会把当前游客 `clientId` 下的行程迁移到账号 `user:{id}`。
- JSON 本地持久化新增 `users` 数据；MySQL 存储层新增 `users` 表和游客行程迁移逻辑。
- 前端新增顶部账号面板，支持注册、登录、退出。
